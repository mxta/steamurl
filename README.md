Source code for https://steam.forfish.es, a steam:// redirector

#How to use
Get the appid of the game: https://store.steampowered.com/app/<appid>/<title>/ -> https://steam.forfish.es/<appid> -> steam://launch/<appid> -> Game is launched

Example:
Garry's Mod
https://store.steampowered.com/app/4000/Garrys_Mod/ -> The store page for gmod. "4000" is the appid
https://steam.forfish.es/4000 -> redirects to steam://launch/4000 -> Garry's Mod launches.

I made this because https://steam.forfish.es/4000 works as a link on Discord, steam://launch/4000 does not.
So you can use this to send your friends a link that launches a game (assuming they have a browser open and already accepted this once manually)
